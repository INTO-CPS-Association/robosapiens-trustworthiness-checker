# Sources and influences

This skill is an original synthesis grounded primarily in this repository's dataflow architecture documentation and informed by the following public guidance. It does not copy any source wholesale.

## Repository model

- `src/dataflow/mod.rs` — semantic-first architecture explanation, running example, traces, executable documentation, state and lifecycle treatment, failure policy, and optimization boundary.
- `docs/src/assets/dataflow/*.svg` — companion figures and visual explanations.

Repository content remains subject to the repository's license.

## Documentation guidance

- [Diátaxis: Explanation](https://diataxis.fr/explanation/) — explanation-oriented documentation and its distinction from tutorials, how-to guides, and reference.
- [Google developer documentation style: Active voice](https://developers.google.com/style/voice) — direct attribution of actions.
- [Google developer documentation style: Examples](https://developers.google.com/style/examples) — useful and readable technical examples.
- [Google developer documentation style: Word list](https://developers.google.com/style/word-list) — consistent technical wording.
- [`anivar/developer-docs-framework`](https://github.com/anivar/developer-docs-framework) — reviewed as a reusable developer-documentation workflow (MIT license).

## Plain-writing and anti-slop guidance

- [`Ryuketsukami/ste-plain-writing`](https://github.com/Ryuketsukami/ste-plain-writing) — reviewed for plain technical writing practices (MIT license).
- [`theclaymethod/unslop`](https://github.com/theclaymethod/unslop) — reviewed for removing formulaic, vague, and inflated prose while preserving substance (MIT license as identified in its skill metadata).

The preservation-first rule in this skill is deliberate: anti-slop editing must not erase modal strength, ordering, ownership, bounds, failure behavior, citations, or useful technical repetition.

Links were reviewed during skill design in August 2026. Recheck upstream content and licensing before redistributing excerpts from those projects.
